# Chip 8 Emulator

## Chip 8 Hardware
- 0xFFF bytes of memory
- 16 8-bit data registers, named V0 through VF. VF doubles as the carry flag.
- A 16-bit address register, I, used to access memory
- A 16-bit program counter and a stack
